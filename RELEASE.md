# 🎮 Jogo de Damas v1.0.0 - Lançamento Inicial

## 🚀 Novidades

**Jogo de Damas clássico completo agora como Progressive Web App!**

### ✨ Destaques

- 🎯 **10 níveis de dificuldade** com sistema de desbloqueio
- 🤖 **IA inteligente** com algoritmos avançados
- 🎨 **Totalmente personalizável**: 6 cores e 5 temas de tabuleiro
- 🎵 **Experiência imersiva**: música de fundo e efeitos sonoros
- 📱 **PWA completo**: funciona offline e é instalável
- 🎮 **Dois modos**: jogador local ou contra a máquina

### 🆕 Melhorias

- ✅ Música de fundo inteligente (toca apenas durante o jogo)
- ✅ Interface otimizada e responsiva
- ✅ Preparado para Play Store via PWA Builder
- ✅ Sistema de progressão de níveis
- ✅ Salvamento automático de preferências

## 🎯 Como Usar

**Jogar Online:** https://lucio12carvalho.github.io/Jogos/

**Instalar como App:**
1. Acesse o site no mobile
2. Toque em "Instalar App" quando aparecer o prompt
3. O app será instalado na sua tela inicial

**Gerar APK/AAB:**
- Use o PWA Builder: https://www.pwabuilder.com/
- Consulte `GUIA_PWA_BUILDER.md` para instruções
